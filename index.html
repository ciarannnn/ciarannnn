02Project

Daniel Caesar Tribute

Fan tribute website · Personal project

A multi-section tribute website dedicated to my favorite artist, Daniel Caesar. It includes a biography, an interactive discography slider with album release dates on hover, and an embedded video of his most streamed song. I also built a light and dark theme toggle that remembers the visitor's choice, and made the layout responsive for phones and desktops. This project taught me how to structure a page with Flexbox, build a scrolling slider with JavaScript, and store user preferences with localStorage.
